# Learnings

- **Docker entrypoint on Windows**: CRLF in `docker-entrypoint.sh` causes `exec ... no such file or directory`. Fix with `sed -i 's/\r$//'` in Dockerfile.
- **Docker build context**: Without `data/` in `.dockerignore`, first build sent ~20GB; with `data/` ignored, rebuild ~36s.
- **PST resume**: After worker restart, BullMQ resumes `process-mailbox`; duplicates are skipped — does not rewrite EML for existing rows.
- **Option B**: Local image includes PST fix; full archive correction needs ingestion source deletion (`ENABLE_DELETION=true`) and fresh PST Import.
